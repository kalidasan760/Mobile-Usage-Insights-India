# Mobile Usage Insights in India - Dashboard

An interactive data visualization dashboard designed to analyze mobile usage habits, user demographics, and digital consumption trends across India.

## 📊 Dashboard Overview

The dashboard features a clean, card-based interface with sidebar filters and detailed visual analytics:

*   **Total Users:** 111 tracked profiles
*   **Average User Age:** 38.64 years
*   **Average Usage Hours:** 6.50 hours daily
*   **Average Data Usage:** 25.57 GB

### Key Analytical Sections
*   **Device Type & Brand Distribution:** Visual breakdown of popular phone brands (including Motorola, Samsung, Apple, and Vivo) alongside comparative metrics between Android and iPhone users.
*   **Primary Usages:** Categorization of digital activities into Education, Entertainment, Gaming, Social Media, and Work.
*   **Time Allocation:** Tracked averages for Social Media (3.36 hours), Streaming (4.30 hours), and Total Screen Time (6.50 hours).
*   **Geographic Spread:** Regional user mapping covering major locations like Jaipur, Pune, Kolkata, and Mumbai.

## 🎛️ Interactive Filters

The left-hand sidebar includes multi-parameter controls allowing users to filter data dynamically by:
*   Age & Gender
*   Phone Brand & Monthly Recharge
*   Apps Installed & Call Duration
*   Gaming Time
